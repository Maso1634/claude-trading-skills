Setting up the Flex Query (once)

  1. In IBKR Client Portal, open Performance & Reports → Flex Queries and add an Activity Flex Query.
  2. Tick only the Trades section, choose Execution, and select all fields.
  3. Format XML, period Last 365 Calendar Days, date yyyyMMdd, time HHmmss, separator ;.
  4. For the Fetch button: Settings → Account Settings → Reporting → Flex Web Service, generate a token, and put it and the query ID in .env.

Stocks, ETFs and options are imported with their real times and commissions; currency trades and other asset types are skipped. Each trade has an IBKR trade ID, so fetching again only adds new trades. Expired, assigned and exercised options close at $0.

Import Robinhood activity CSV

Getting the file

  1. In the Robinhood app or website, open Account → Reports and statements → Reports.
  2. Generate an account activity report for the dates you want, then download the CSV.
  3. Upload it here. Importing the same file twice is safe: rows already in the journal are skipped.

Stocks, ETFs and options are imported. Dividends, deposits, interest and transfers are skipped. Robinhood's file only has dates, not times, so imported fills show a date only. Each option contract becomes its own trade; use Merge on a trade's page to join the legs of a spread. Don't also type in a trade by hand that you're going to import, or it will be counted twice.
